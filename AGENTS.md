# ProFinda Prototype

This folder is a ProFinda prototype environment.

The ProFinda component rules are loaded automatically from your OpenCode global instructions (`ProFindaComponents.md`). If you don't see the rules active, ask your team lead to add the `instructions` URL to your `opencode.json`.

## This session: prototype mode is ON

- Always query the `communities-storybook` MCP before writing any UI
- If no `package.json` exists — scaffold the Vite app first, run `npm install && npm run dev`, tell the user the URL
- Every prototype must look exactly like the real ProFinda platform
- Speak in plain language — the user is not a developer
