# ProFinda Prototype

Build ProFinda-looking prototypes from screenshots and ideas. No coding required.

---

## Setup (one-time)

Add this to your `~/.config/opencode/opencode.json`:

```json
"instructions": [
  "https://raw.githubusercontent.com/pedrorodrigopro/ProFindaComponents/main/ProFindaComponents.md"
]
```

If you already have other entries in your config, just add the `"instructions"` key alongside them. It won't affect anything else you use OpenCode for.

Ask your team lead to also set up the `communities-storybook` MCP — one more line in the same file.

---

## How to prototype

1. Open OpenCode in any empty folder
2. Upload a screenshot of any ProFinda screen — or describe your idea in plain language
3. OpenCode builds a running prototype that looks exactly like the real platform
4. Keep chatting: *"add a filter bar"*, *"change this to a table"*, *"add a match card here"*
5. Your prototype runs at **http://localhost:5173**

---

## To share

Ask OpenCode: *"export this so I can share it"*

It builds a portable file you can email or upload.
