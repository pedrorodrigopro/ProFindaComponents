# ProFinda Prototype Starter

Turn any idea into a ProFinda prototype in minutes — no coding required.

## How to use

1. **Copy these two files** into any empty folder on your machine:
   - `AGENTS.md`
   - `ProFindaComponents.md`

2. **Open OpenCode** in that folder

3. **Upload a screenshot** of a ProFinda screen you want to replicate, or just describe your idea

That's it. OpenCode builds and runs the prototype for you.

## What you get

- A running prototype at `http://localhost:5173`
- Looks exactly like the real ProFinda platform
- You can keep asking for changes in plain language
- Export with `npm run build` to get a shareable file

## Requirements

- [OpenCode](https://opencode.ai) installed
- The `communities-storybook` MCP configured in your OpenCode settings (ask your team)
