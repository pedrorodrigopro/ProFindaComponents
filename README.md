# ProFinda Prototype

Build ProFinda-looking prototypes from screenshots and ideas. No coding required.

---

## How to start a prototype session

Open OpenCode in any empty folder and say:

> "Use these instructions when building: https://raw.githubusercontent.com/pedrorodrigopro/ProFindaComponents/main/ProFindaComponents.md"

Then upload a screenshot of any ProFinda screen — or just describe your idea.

---

## What happens next

- OpenCode reads the ProFinda component rules
- Checks what real platform components match what you're describing
- Builds a running prototype that looks exactly like the real platform
- Your prototype runs at **http://localhost:5173**

Keep chatting to evolve it:
*"add a filter bar here"*, *"change this to a table"*, *"add a match card"*

---

## To share

Ask OpenCode: *"export this so I can share it"*

It builds a portable file you can email or upload.

---

## Requirements

The `communities-storybook` MCP must be configured in OpenCode (ask your team lead — one-time setup per machine).
